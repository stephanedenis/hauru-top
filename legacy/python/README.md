# Ancienne implémentation Python

Cette version Python de `hauru-top` est conservée pour référence. **La version
active et maintenue est le binaire Rust, à la racine du dépôt.**

```bash
python3 -m pip install --user -r requirements.txt
python3 haaru-top.py
```

Mêmes options et mêmes touches que la version Rust.
